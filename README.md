# Dave Digger Bot

A little [PICO-8](https://www.lexaloffle.com/pico8.php) dig-'em-up. Dave tunnels through the dirt, grabs the diamonds, and lobs chickens at the bots that chase him down.

## ▶️ Play

**https://andyreagan.github.io/dave-digger-bot/**

## How to play

- **Arrow keys** — dig / move
- **Z** (or **C**) — throw a chicken in the direction you're facing

Collect every diamond to clear a level. A bot touching Dave costs a life; you have three. The bots start slower than Dave, match his speed around level 8, and ramp up to **twice** his speed in the late game — so keep digging escape routes and keep throwing.

## Files

- `index.html` / `index.js` — the web export you're playing
- `dave_digger_bot.p8` — the PICO-8 source cart (open it in PICO-8 to tinker)
